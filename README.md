Loan Portfolio Monitoring Project using Excel

Project Overview

This is a beginner-level finance project developed using Microsoft Excel to understand how loan portfolios can be monitored and analysed. The project uses fictional loan data to demonstrate basic portfolio monitoring concepts.

Project Objectives

- Track loan details and outstanding principal.
- Calculate principal repayments and estimated annual interest.
- Monitor payment due dates and loan maturity dates.
- Identify overdue loans using Excel formulas.
- Apply basic risk indicators to loans.
- Analyse outstanding portfolio exposure.
- Summarise key portfolio metrics through a dashboard.

Tools Used

- Microsoft Excel
- Excel formulas and functions
- Conditional formatting
- Charts and dashboard visualisation

Key Features

- Loan Tracker: Organises loan-level information, repayment details, and monitoring indicators.
- Repayment Analysis: Calculates principal repaid and outstanding principal.
- Payment Monitoring: Flags overdue payments based on due dates and payment status.
- Basic Risk Indicators: Highlights overdue loans for further review.
- Portfolio Exposure Analysis: Calculates each loan's share of total outstanding principal.
- Portfolio Dashboard: Summarises key metrics, including original loan amount, outstanding principal, principal repaid, and estimated annual interest.

Key Learning Outcomes

Through this project, I practised Excel formulas, financial calculations, conditional formatting, and dashboard creation. I also developed a better understanding of how loan-level data can support portfolio monitoring and help identify areas that may require further review.

Important Note

This is a self-created learning project using fictional data. The interest calculations and risk indicators are simplified for educational purposes and should not be treated as a professional credit-risk assessment.
